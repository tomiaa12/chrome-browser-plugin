This Privacy Policy explains how the Chrome extension “解密抓包远程调试助手” (the “Extension”) collects, processes, stores, and shares user data. The Extension is a local developer debugging tool. It handles personal or sensitive user data that may appear in network traffic and page context (web browsing activity, website content, authentication cookies/tokens, and information inside request and response bodies). Data is processed on your device by default. Optional features that send data off-device run only after you turn them on.

本隐私权政策说明 Chrome 扩展「解密抓包远程调试助手」（以下简称「本扩展」）如何 收集、处理、存储和共享用户数据。本扩展是本地开发调试工具，会处理网络请求与页面上下文中可能出现的个人或敏感用户数据（网页浏览活动、网站内容、身份验证 Cookie/Token，以及请求/响应体中的信息）。默认在您的设备本地处理；只有您主动开启的可选功能才会把数据发到设备外。

Before the Extension processes the data described below, it shows an in-product disclosure and asks you to take an affirmative action (check the box and click Agree). Installing the Extension or using it does not by itself constitute consent.

在处理下述数据之前，本扩展会在产品界面内醒目披露，并要求您采取明确动作（勾选并点击「同意」）。仅安装或打开扩展本身不构成同意。

1. Who we are / 我们是谁

The Extension is maintained by Network Monitor Pro Team for developers. Its single purpose is local network-request monitoring, API decrypt/inspect, mock, remote debugging assistance, and related developer tools.

本扩展由 Network Monitor Pro Team 维护，面向开发者。单一用途是：本地网络请求监控、接口解密查看、Mock、远程调试辅助及相关开发工具。

2. Collection / 收集

The Extension collects the following categories of data when you agree and use the corresponding features. Collection happens on your device via Chrome extension APIs (including debugger, webRequest, cookies, tabs, scripting, storage, host permission <all_urls>) and content scripts.

在您同意并使用相应功能后，本扩展会在设备本地通过 Chrome 扩展 API （包括 debugger、webRequest、cookies、 tabs、scripting、storage、主机权限 <all_urls>）及内容脚本收集下列数据。

  • Web browsing activity / 网页浏览活动： request URLs, methods, resource types, status codes, timing; page and tab URLs and titles. 请求 URL、方法、资源类型、状态码、耗时；标签页与页面 URL、标题。
  • Website content and resources / 网站内容与资源： HTTP request and response headers and bodies, DOM/page context used for debugging, screenshots you trigger, console logs during remote debug, JSBridge/debug helper output. HTTP 请求/响应头与正文、调试所需的页面/DOM 上下文、您触发的截图、远程调试时的控制台日志、JSBridge 等调试输出。
  • Authentication information / 身份验证信息： cookies, session keys, tokens, and similar fields (for example session, rndKey, userInfo, uin) when you use capture, account-sync, or related debug features. 在抓包、账号同步等调试功能中读取的 Cookie、会话密钥、Token 及同类字段。
  • Personally identifiable and other sensitive data that may appear in traffic / 流量中可能出现的个人身份及其他敏感信息： names, usernames, phone numbers, account IDs, form data, or financial fields if they appear in the pages or APIs you debug. The Extension does not ask you to submit identity information for accounts, marketing, or analytics. 若您调试的页面或接口中出现姓名、用户名、手机号、账号 ID、表单或财务字段，本扩展会在本地抓包中看到它们。本扩展不会为注册、营销或统计分析而要求您提供身份信息。
  • Extension settings / 扩展配置： rules, toggles, panel state, optional API keys or tokens you save (AI, Figma, webhooks), stored in chrome.storage (local and, for some settings, sync). 规则、开关、面板状态，以及您保存的可选 API Key / Token（AI、Figma、Webhook 等）。
  • Clipboard / 剪贴板： written only when you copy debug content. 仅在您主动复制调试内容时写入。

The Extension does not collect analytics, advertising identifiers, or usage telemetry. It does not require an account with the publisher.

本扩展不收集统计分析、广告标识或使用遥测，也不要求向发布者注册账号。

3. Processing / 处理

Collected data is processed only to provide the Extension’s disclosed single purpose:

处理目的仅限于本扩展已披露的单一用途：

  • Display, filter, format, decrypt, and inspect captured network requests in the panel. / 在面板中展示、过滤、格式化、解密和查看抓包。
  • Bind debugging tools to the target tab or remote device you select. / 将调试能力绑定到您选择的标签页或远程设备。
  • Account-sync and login helpers for environments you choose to debug. / 在您选择调试的环境中做账号同步与登录辅助。
  • Mock, screenshots, design-diff, flow charts, and in-page debug helpers. / Mock、截图、设计稿比对、流程图与页内调试辅助。
  • Optional remote debug (local Chii/Whistle or the online Chii you enable). / 可选远程调试（本机 Chii/Whistle，或您开启的线上 Chii）。
  • Optional AI, Figma, GitLab, Feishu, CMDB, and MCP tools you configure and invoke. / 您自行配置并触发的 AI、Figma、GitLab、飞书、CMDB 与 MCP 工具。
  • Remember your settings. / 保存您的配置。

We do not process user data for advertising, credit-worthiness, lending, or resale. Processing is performed locally in the browser except when you enable an optional off-device feature listed under Sharing.

我们不会将用户数据用于广告、信用评估、借贷或转售。除您主动开启「共享」一节所列的可选功能外，处理均在浏览器本地完成。

4. Storage / 存储

Default storage is on your device only. The publisher does not operate a backend that stores your captured traffic.

默认仅存储在您的设备上。发布者不以自有后端保存您的抓包内容。

  • Session debug data / 会话调试数据： kept in memory or the open panel; typically cleared when you clear the list, close the page, reload the extension, or uninstall. 保存在内存或打开的面板中；清空列表、关闭页面、重载或卸载扩展后通常清除。
  • Settings and keys you save / 您保存的配置与密钥： chrome.storage.local and, for some AI/settings, chrome.storage.sync (synced with your Chrome profile). You can delete them by clearing extension data, resetting, or uninstalling. 部分配置会随 Chrome 账号同步。可通过清除扩展数据、重置或卸载删除。
  • Account-sync cache / 账号同步缓存： stored locally for the debug environments you use, until you clear it. 保存在本地，直到您手动清除。
  • Local debug services / 本机调试服务： if you run Whistle, Chii, or the MCP bridge on localhost, those processes store data under your control (for example 127.0.0.1:8899, 127.0.0.1:18080, ws://127.0.0.1:9527). 若您在本机运行 Whistle、Chii 或 MCP 桥接，数据由您控制的进程保存。

The publisher does not hold a cloud copy of your capture data and cannot remotely delete data that exists only on your device. If you sent data to a service you enabled (online Chii, AI API, Figma, Feishu, etc.), retention follows that service’s policy.

发布者不持有您抓包数据的云端副本，也无法远程删除仅存在于您设备上的数据。若您把数据发到自己开启的服务（线上 Chii、AI、Figma、飞书等），保留期限以该服务的政策为准。

5. Sharing / 共享

We do not sell, rent, or share user data for advertising. We do not transfer captured traffic to the publisher’s servers. Data leaves your device only in the following cases, which you initiate:

我们不会出售、出租用户数据，也不会用于广告。不会把抓包内容上传到发布者服务器。数据仅在下列由您主动发起的情形下离开本机：

  • Online remote debug / 线上远程调试： if you enable online Chii, page content, network logs, and console data may be sent to https://web.mfosunhani.com/engine/chii (operator of that host). Local Chii uses http://127.0.0.1:18080 and stays on your machine. 若您开启线上 Chii，页面内容、网络与控制台数据可能发往该主机运营方；本地 Chii 仅走本机。
  • User-configured AI APIs / 您配置的 AI 接口： prompts and context you submit are sent to the API URL you save (default example: https://aigw.finloopai.ai/v1/chat/completions, or another endpoint you enter). 您提交的提示词与上下文会发往您保存的 API 地址。
  • Figma： if you save a Figma token, the Extension calls Figma APIs you request. 若您保存 Figma Token，将按您的操作调用 Figma API。
  • Feishu / GitLab / CMDB / other tools you open： requests go to the URLs you configure or the sites you already have open in the browser. 请求发往您配置的地址，或您已在浏览器中打开的站点。
  • Local MCP client / 本机 MCP 客户端： if you run the local MCP bridge, debug data may be read by the AI client on your machine over ws://127.0.0.1:9527. That client is under your control. 本机 MCP 桥接会把调试数据提供给您本机的 AI 客户端，由您控制。
  • Legal / 法律要求： if required by law or a valid legal process. 法律法规或有权机关依法要求时。

Parties that may receive data: (1) you; (2) services you explicitly enable or configure (online Chii host, your AI provider, Figma, Feishu, GitLab, CMDB, localhost debug tools, your local MCP/AI client); (3) authorities when legally required. The publisher is not one of those recipients for captured traffic.

可能接收数据的主体：(1) 您本人；(2) 您明确开启或配置的服务（线上 Chii 主机、您的 AI 服务商、Figma、飞书、GitLab、CMDB、本机调试工具、本机 MCP/AI 客户端）；(3) 依法有权的机关。发布者不是抓包内容的接收方。

6. Permissions / 权限说明

Permissions are used only for the purposes above:

权限仅用于上述用途：

  • tabs / scripting / sidePanel：target the page and show the panel. / 定位目标页并提供面板。
  • debugger：capture and analyze network requests; mobile viewport emulation. / 捕获与分析网络请求；移动端视口模拟。
  • webRequest：show pending requests in the list. / 在列表中展示进行中的请求。
  • cookies：read cookies needed for debug/account-sync/CMDB helpers. / 读取调试、账号同步、CMDB 辅助所需 Cookie。
  • storage：save settings and consent. / 保存配置与同意状态。
  • clipboardWrite：copy debug content you request. / 按您的操作复制调试内容。
  • host_permissions: <all_urls>：run debug helpers on the sites you inspect. / 在您检查的站点上运行调试辅助。

7. Consent, opt-out, and local-only mode / 同意、停用与仅本地模式

Core capture, decrypt, and inspect features run locally after you agree in the in-product dialog. That local-only mode is the default. You can refuse consent and not use the Extension. You can later clear data or uninstall. Optional off-device features (online remote debug, AI, Figma, webhooks) stay off until you enable them. There is no analytics collection to opt out of.

核心抓包、解密、查看功能在您于产品内同意后仅在本地运行，这就是默认的仅本地模式。您可以拒绝同意并停止使用。之后可清除数据或卸载。线上远程调试、AI、Figma、Webhook 等可选功能默认关闭，直至您开启。本扩展不收集统计分析。
